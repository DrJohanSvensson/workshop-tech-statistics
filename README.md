### Pre-Workshop Setup:

For this workshop, we will be covering a lot of ground in a short time (Python, APIs, web scraping, git, VS Code). To participate, you must have a working environment ready **before** the session begins. You have two options for setting up your environment:

---

#### Option A: GitHub Codespaces (Easier) 
This repository is set up as a [GitHub codespaces](https://github.com/features/codespaces) cloud environment. It requires zero installation and works exactly the same in most browsers.

1. Create a GitHub account at [github.com](https://github.com/signup) if you don't already have one.
2. Log in and click the green **"<> Code"** button near the top right on this page.
3. Select the **"Codespaces"** tab in the dropdown menu.
4. Click **"Create codespace on main"**.
5. Once the dark-themed editor (VSCode) appears, wait 2-5 minutes for the environment to build. 

---

#### Option B: Local Installation (Recommended for future use)
If you want to keep using these tools later or already have many of these tools installed, you can install everything on your own machine. **Due to time constraints, we will not be able to troubleshoot local installation errors (like PATH issues etc.) during the workshop.**. Install the newest versions of the following tools:

2. **Git:** Download and install from [https://git-scm.com/](https://git-scm.com/).
4. **uv** (Python virtual environments/package manager): Download and install from [https://docs.astral.sh/uv/getting-started/installation/](https://docs.astral.sh/uv/getting-started/installation/). The tool will install python later if you don't have it already.
5. **Visual Studio Code (VSCode):** Download and install from [https://code.visualstudio.com/](https://code.visualstudio.com/).
6. **VSCode Extensions:**. Open VSCode, go to the Extensions tab in the left sidebar, and install these extensions:
   - **Python** (`ms-python.python`) — Core Python support: running files, linting, interpreter selection
   - **Jupyter** (`ms-toolsai.jupyter`) — Run Python in interactive mode and `.ipynb` notebooks inside VS Code
   - **GitHub Copilot** (`GitHub.copilot`) — AI code completions as you type
   - **GitHub Copilot Chat** (`GitHub.copilot-chat`) — Chat panel to ask Copilot questions in plain language
   - Optional but useful
      - **Pyrefly** (`meta.pyrefly`) — Meta's Python type checker; flags type errors as you write code
      - **Data Wrangler** (`ms-toolsai.datawrangler`) — For exploring, cleaning, and transforming tabular data in Python
      - **GitLens** (`eamodio.gitlens`) — Enhanced Git support with line blame, commit history, and code change exploration
      - **R** (REditorSupport.r) — Core R support: syntax highlighting, code completion, linting, run code in terminal, view data/plots/help pages, and R Markdown support
      - **R Debugger** (REditorSupport.r-debugger) — Interactive debugger for R; lets you step through R code and inspect variables
